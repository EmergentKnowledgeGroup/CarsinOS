# Support

Use GitHub issues for reproducible bugs and focused feature requests. Start
with the [Getting started guide](docs/GETTING_STARTED.md) and include your
CarsinOS commit, operating system, the smallest reproduction, and sanitized
logs when they help.

For suspected vulnerabilities, use [private vulnerability reporting](SECURITY.md)
instead of a public issue.

This project is source-first while its new public repository is established;
there is no promise of a support SLA or hosted service.
