# Releases

No packaged GitHub release is published from this freshly established public
repository yet.

Until that changes, clone and build CarsinOS from source using
[Getting started](GETTING_STARTED.md). A local build is not a vendor-signed
installer, and this repository does not currently claim one.

When a release is published, this page will link the exact GitHub release,
platform support statement, checksum or signing information, upgrade notes,
and known boundaries. Do not rely on installers, hashes, or release links from
unofficial mirrors.
