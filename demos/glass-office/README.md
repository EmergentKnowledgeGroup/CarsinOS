# Glass Office interactive demo

Double-click **START-DEMO.cmd**, or open **index.html** in your browser.
No installation, server, account, API key, or gateway is required.

This is the original recovered elevator design prototype, packaged for local
use. It uses simulated data and does not execute real work or change accounts.
Reload the page to reset the demo.

## Try it

- **4 / The Office:** briefing, decisions, work cards, Arrange office, and the
  simulated notification interaction.
- **3 / The Window:** animated crab crew and simulated office chatter. Click a
  crab to see its task.
- **2 / The Trenches:** switch among the prototype's operational tabs.
- **B / The Basement:** inspect the prototype's machinery/settings view.
- **After hours:** toggle the light and dark themes.

Some controls intentionally show a "Would..." message. Those are prototype
placeholders, not implemented backend operations. The prototype's COLACK label
is a historical design reference, not an installed integration.

## Provenance

Recovered from the July 22, 2026 design session: last HTML write plus 15 matching
edits. The owner confirmed this as the intended elevator design on September 4.
Packaging adds UTF-8 metadata, a demo title/label, and this launcher; the design
and its interactions are preserved.
